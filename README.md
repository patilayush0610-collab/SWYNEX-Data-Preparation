# SWYNEX – Data Preparation and Cleaning

## Internship Task 1

**Objective:** Prepare and clean a sales dataset for Power BI analysis.

## Tools Used
- Microsoft Excel
- Power BI Desktop
- Power Query

## Data Cleaning Steps
1. Removed duplicate Order IDs.
2. Trimmed extra spaces from text columns.
3. Removed records with missing Quantity.
4. Replaced invalid Order Date values with blank values.
5. Changed column data types.
6. Created a Calculated Sales column using Quantity × Price.
7. Checked calculated sales values against the original Sales column.

## Files Included
- `SWYNEX_Task1_Sales_Dataset.xlsx` – Dataset
- `SWYNEX-Data-Preparation.pbix` – Power BI project

## Outcome
The dataset was cleaned and prepared for further business analysis in Power BI.
